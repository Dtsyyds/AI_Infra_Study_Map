给定长度为 n 的数组 nums，返回其中的多数元素。多数元素是出现次数严格大于 n // 2 的元素，题目保证多数元素一定存在。

暴力解法如何做，时间复杂度是多少？
使用字典时，键和值分别保存什么？
是否必须统计完整个数组才能返回？
哈希解法的时间和空间复杂度分别是什么？
题目保证多数元素超过一半，这个特殊条件能否让我们不用字典，只使用两个变量解决？

1. 挨个遍历数组,对于每个元素,统计其中出现次数, 若超过 n // 2 则返回该元素。时间复杂度为 O(n^2)。
2. 使用字典,字典的键是数组元素,值是该元素出现的次数。
3. 不一定,返回大于 n // 2 的元素即可。
4. 时间复杂度为 O(n),空间复杂度为 O(n)。
5. 假设每次从数组中消掉两个不同元素。因为多数元素比其他元素加起来还多，所以无论怎样成对抵消，最后都一定会剩下多数元素。
