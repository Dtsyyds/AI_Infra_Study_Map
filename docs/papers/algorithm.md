```python

```

| ------- | ------: |

哈希表；
```python

    "alice": 20,

```

| -------- | ---: |

集合；
```python
seen = {"alice", "bob"}
```

栈；


队列；
```python

queue = deque([1, 2])

value = queue.leftpop()
```
先进先出，用于广度优先搜索,BFS,请求排队，任务调度

数据结构是组织数据的方式
程序是算法和数据结构的实现
一个单层循环是 O(n), 嵌套循环是 O(n^2)
列表查找是 O(n)，因为需要遍历整个数组,空间复杂度是 O(1)
依次遍历找是否存在重复元素，或者将没有匹配的元素存入集合，再进行查找。前者需要 n 次比较，后者最多 2n 次比较（因为集合查找是 O(1)）。



## LRU Cache

目标：实现支持以下操作的缓存：

get(key)
put(key, value)

要求平均时间复杂度：

get: O(1)
put: O(1)

淘汰规则：

容量满时，删除最久没有被访问的元素。

先不写代码，请思考：

只使用哈希表，为什么无法在 O(1) 时间找到最久未使用元素？
只使用链表，为什么无法在 O(1) 时间找到指定 key？
要同时满足 O(1) 查找、移动和删除，需要组合哪两种数据结构？
容量为 2，依次执行：
put(1, A)
put(2, B)
get(1)
put(3, C)

最后应该淘汰 key 1 还是 key 2？为什么？

#### 自己的理解：
哈希表：按 key 查找 O(1)，但不知道谁最久未使用。
普通链表：按 key 查找 O(n)，但已知节点时，双向链表可以 O(1) 删除和移动。
哈希表：key → Node
双向链表：维护使用时间顺序
哈希表负责定位；
双向链表负责排序、移动和淘汰。
