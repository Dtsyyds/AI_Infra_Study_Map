## 产品范围

为维护小型Python项目的开发者提供：登记受控仓库版本 → 提交缺陷及验收条件 → 查看候选/测试 → 人工审查 → 下载补丁，后续对授权仓库创建草稿PR。首版固定依赖和可信测试入口；模型不能选择任意镜像、执行命令或修改验收标准。采购审核保留回归用途。

页面：项目管理、新建任务、任务中心、任务详情（步骤/候选、代码差异/测试、预算/操作）、补丁审查、运维评测。运行结果、验证结果、审批结果、外部交付结果分别展示。新审批与已有UNKNOWN副作用对账分别建模；审批绑定基准版本、候选哈希和验证身份，内容变化使审批失效。

## 第一次学习任务

阅读顺序：`api/main.py` 的 `submit` 路由对应实现 → `Store.submit/claim` → `runtime/orchestrator/worker.py` → `core/kernel.py` → `Store.prepare/checkpoint`。以实际函数名为准，用自己的话画出请求、事务、Worker、工具和Artifact之间的关系。
